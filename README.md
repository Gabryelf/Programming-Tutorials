## 📖 О проекте

**NeoCode** — это образовательная платформа, созданная для удобного изучения языков программирования. Проект представляет собой набор стильных, современных HTML-страниц, организованных в виде:

- 🎯 **Удобный интерфейс** с карточками курсов, ссылками и базой знаний (в разработке).
- 🗺️ **Кодовая база** для каждого языка с пошаговым погружением и личными кейсами.
- 📚 **Документация** файлы для каждого урока с кодом и теорией

Все уроки имеют подсказки, маркеры и визуальные шаблоны. Код в приложениях выполнен в нескольких вариациях для расширенного понимания темы.

---

## 🚀 Особенности

- ✦ **Инструктаж** — я предлагаю тот формат, который соответствует общим мировым стандартам.
- ✦ **Интерфейс** — на каждый урок легко выйти через главный сайт по ссылки в `about`.
- ✦ **Road-map структура** — по каждому языку мы пройдем все технологии, от основ и теории до практики и рабочего прототипа приложения.
- ✦ **Методология** — не просто изучение программирования, а обучение гибкому подходу!
- ✦ **Интеграция** — наши приложения от простого личного использования до профессиональных и востребованных.
- ✦ **Кейсы** — иногда тот или иной подход можно узнать только из долгих тренировок, именно такой опыт я стараюсь предоставить.
