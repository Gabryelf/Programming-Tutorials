# 🃏 Hover-карточка — плавная анимация

**Что ты изучишь:**  
- псевдокласс `:hover`  
- CSS свойство `transition`  
- трансформации `transform: translateY()` и `scale()`  

## 🎯 Задание (перепиши сам)
1. Создай свою карточку с иконкой, заголовком и текстом.  
2. Добавь эффект при наведении — пусть карточка **слегка поворачивается** и меняет цвет фона.  
3. Экспериментируй со скоростью `transition`.

## 🔍 Код к объяснению
- `transition: all 0.3s` — плавно анимируем все изменяемые свойства  
- `.card:hover` — срабатывает, когда мышь над блоком  

**Визуальный результат:** карточка поднимается, тень усиливается, кнопка проявляется — смотри в `index.html` живую демку.
